# Guia para Iniciantes 🌱

Bem-vindo ao laboratório Amazon EC2!

Este guia foi criado para ajudar quem está começando
a estudar computação em nuvem.

## O que você vai aprender?

- O que é computação em nuvem
- O que é uma instância Amazon EC2
- Como funciona um servidor web Apache
- Como proteger o acesso com Security Groups
- Como monitorar recursos com CloudWatch

> Este documento será desenvolvido passo a passo,
> com explicações simples e exemplos práticos.
