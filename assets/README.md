
# Recursos visuais

Esta pasta reúne os elementos gráficos utilizados na
documentação do laboratório Amazon EC2.

## Organização

- `banner.png`: identidade visual do projeto.
- `arquitetura.png`: diagrama da infraestrutura AWS.
- `screenshots/`: evidências reais do laboratório.

Os recursos visuais têm como objetivo facilitar a
compreensão técnica e melhorar a experiência de leitura.
